# Reading List / Source Register

## Conventions (used across `/work/`)
- Each source has an ID `S##` (e.g., `S01`) used for citations as `[S##]`.
- Optional locator format: `[S##: p.12]`, `[S##: ch.3]`, `[S##: sec.2.1]`.
- Each entry records: full citation, source date, access date, and a stable link (URL/DOI or repo path).
- Evidence level tags:
  - **Primary:** original argument/data.
  - **Secondary:** synthesis/interpretation of primary sources.
  - **Tertiary:** encyclopedia/overview/blog; use sparingly for non-central claims.
