# Project brief (edit me)

## Objective
Produce an auditable research proposal on **memetics** (as a candidate framework for cultural evolution), including:
- evidence pack + competing framings,
- hypothesis portfolio (testable, falsifiable),
- study designs + experiment plan,
- reading list (primary sources first).

## Constraints
- Every nontrivial factual claim must carry a citation and a date.
- Prefer primary / peer‑reviewed / canonical sources over blogs.
- Keep uncertainty explicit; mark unknowns and contested claims.

## Output format
All deliverables live under `/work/` (see `work/00_deliverables_manifest.md`).

## Stop conditions
- If evidence quality is too low for confident claims, **abstain** and propose the next evidence to fetch.
- If a subtopic becomes unbounded, write a scope note and park it.

## Notes
- This workspace is designed to be resilient to interruptions: progress is stored as files + checkpoints.
